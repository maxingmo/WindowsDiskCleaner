# P9A 主界面布局优化设计

## 总体思路

P9A 只调整 `MainWindow` 的布局和视觉层级。业务状态仍由 `MainWindowViewModel` 管理，命令和绑定名称不变，降低功能回归风险。

## 布局设计

主窗口分为四个区域：

- 顶部操作区：标题、扫描路径、选择目录、开始扫描、取消、删除文件。
- 筛选区：关键词、扩展名、最小 MB、修改日期、快捷筛选、文件级别、清除筛选。
- 结果区：视图切换、批量选择工具、列表视图或文件夹视图。
- 详情区：选中文件风险/路径和运行状态。

每个区域使用轻量边框和白色背景，与窗口浅灰背景区分。

## UI 细节

- 主窗口尺寸提升到 `1320 x 780`，最小尺寸提升到 `1080 x 620`。
- 列表视图增加隔行底色、统一行高和表头高度。
- 主要操作按钮使用蓝色，危险删除按钮使用红色，中性按钮保持白底灰边。
- 底部详情区分两列，左侧是选中文件，右侧是运行状态。

## 风险控制

不改 ViewModel 的属性和命令名称，不改 Core 层。验证以 core tests 和 app build 为准。
