# P10A 分类筛选与文件夹视图精修需求

## 阶段名称

P10A: Category Filter and Folder View Polish

## 目标

继续优化 P9B 清理主页界面，让清理分类卡片从纯展示变成可点击的筛选入口，并让文件夹视图去掉 `[DIR]` / `[FILE]` 这类偏工程化的文本前缀。

## 范围内

- 点击清理分类卡片后，详细结果区筛选到对应分类文件。
- 再次点击当前分类卡片时取消分类筛选。
- 顶部扫描概览显示当前分类筛选状态。
- 分类卡片显示 `点击筛选` 或 `已筛选` 状态。
- 当前选中的分类卡片使用更明显的边框和背景提示。
- 文件夹视图显示文本去掉 `[DIR]` 和 `[FILE]` 前缀。
- 增加 Core 测试覆盖分类筛选规则。
- 增加 App 轻量测试覆盖文件夹显示文本。

## 范围外

- 不实现真实一键清理。
- 不改变删除确认流程。
- 不改变高风险分类规则。
- 不实现左侧导航多页面切换。
- 不实现重复文件检测或图表分析。

## 验收标准

- Core 测试通过。
- App 轻量测试通过。
- App 构建成功并重新生成 `06_Build-Release\FileScannerP2.exe`。
- 点击分类卡片只影响结果筛选，不会触发删除。
- 文件夹视图不再显示 `[DIR]` / `[FILE]` 文本前缀。
