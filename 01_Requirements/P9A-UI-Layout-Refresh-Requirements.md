# P9A 主界面布局优化需求

## 阶段名称

P9A: 主界面布局优化

## 目标

在不改变扫描、筛选、删除等功能行为的前提下，重新组织主窗口 UI，让工具栏、筛选区、结果区、详情区的层级更清楚，提升日常使用手感。

## 范围内

- 将主窗口拆成顶部操作区、筛选区、结果区、底部详情区。
- 顶部操作区突出扫描目录、开始扫描和删除文件操作。
- 筛选条件集中到独立区域。
- 结果区合并视图切换和批量操作条。
- 底部详情区分开显示选中文件信息和运行状态。
- 调整表格行高、隔行底色、边框和窗口尺寸。

## 范围外

- 不改扫描算法。
- 不改筛选逻辑。
- 不改单文件删除或批量删除流程。
- 不新增文件夹删除。
- 不新增重复文件检测或图表分析。

## 验收标准

- App 可以正常编译。
- Core 测试保持通过。
- 现有命令绑定仍然可用。
- Release exe 重新生成。
