# P7 风险筛选与风险详情需求

## 阶段名称

P7: 风险筛选与风险详情

## 目标

在现有文件级别列和安全删除规则基础上，增加按文件风险级别筛选的能力，并在用户选中文件时显示更明确的风险说明，方便删除前快速判断。

## 范围内

- 在筛选栏增加“文件级别”下拉筛选。
- 支持以下筛选项：
  - 全部级别
  - 系统级
  - 程序安装级
  - 用户数据级
  - 缓存/临时级
  - 未知/谨慎级
- 风险级别筛选与关键词、扩展名、最小大小、修改日期、快捷筛选组合生效。
- 在底部状态区域显示当前选中文件的风险级别、风险提示和完整路径。
- 修复快捷筛选标签的中文乱码。
- 保持删除能力不变，不新增文件夹删除或永久删除。

## 范围外

- 文件夹级删除。
- 永久删除。
- 重复文件检测。
- 风险级别颜色主题或图标系统的大规模重做。

## 验收标准

- 选择风险级别后，列表视图和文件夹视图都只显示匹配级别的结果。
- 选择“全部级别”时不按风险级别过滤。
- 清除筛选会恢复到“全部级别”。
- 选中文件时能看到风险说明；未选中文件时显示默认提示。
- Core 筛选逻辑有自动化测试覆盖。
